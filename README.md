# SoboSuika
A Sobosuba mod that adds a Suika inspired game mode.

Tested on Sobosuba v1.3.11


## Installation:
Use [Sobosuba Mod Manager](https://github.com/T0y-9n/sobosuba-mods), or do the following:

Extract `sobosuika.zip` from the [latest release](https://github.com/Typhe681/SoboSuika/releases/latest) into Sobosuba's userdata folder

* **Windows:** `%APPDATA%\Godot\app_userdata\sobosuba`
* **Linux:** `~/.local/share/godot/app_userdata/sobosuba`


It should look like this:
```
├── styles
|   └── suika_bootstrap.tres
└── sobosuika
    ├── suika.gd
    ├── scene_suika.gd
    ├── scene_suika.tscn
    ├── bubble.png
    ├── 4.png
    ├── 8.png
    ├── 16.png
    └── etc...
```
